# 🌐 CyberNews Map — Interactive Global Intelligence Visualizer

An interactive cyberpunk-themed global news visualizer and geopolitical situational awareness terminal built with React 19, Vite, and React Simple Maps.

## ✨ Features

- **Interactive Global Map** — Built with SVG and `react-simple-maps`, featuring interactive country pings and hot zones.
- **Cyberpunk HUD & Aesthetics** — Neon-themed UI with status telemetry, live critical alerts count, and category breakdown.
- **Temporal Playback & Timeline Slider** — Scrub forward or backward in time, or play events with variable speeds (1x, 2x, 5x, 10x).
- **News Terminal** — Real-time event log terminal with severity indicators (Low, Medium, High, Critical) and category filtering.
- **Event Inspection Modal** — Click into any global event to view detailed situational analysis, coordinates, and timestamp.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **react-simple-maps**
- **Lucide React** (Icons)
- **date-fns**
- **Vanilla CSS / Custom Cyber Design System**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/heyitsak/news-map.git

# Navigate to directory
cd news-map

# Install dependencies
npm install

# Start local dev server
npm run dev
```
